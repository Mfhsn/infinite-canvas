# 主页 UI 重构计划：创作启动台

## 状态

- 仅规划，尚未修改任何业务或界面代码。
- 目标仓库：`infinite-canvas-mfh`
- 等待用户批准后执行。

## 需求摘要

1. 完整替换当前主页展示，不要求保留现有提示词图片、标题动效、点阵背景或高亮装饰。
2. 主页从“宣传型落地页”调整为“创作启动台”，优先帮助用户开始、继续或选择创作工具。
3. 保留现有产品能力和路由：画布、生图、视频、提示词、素材；不改后端和生成逻辑。
4. 同时支持中文/英文、浅色/深色、桌面/移动端。
5. 不增加依赖，不依赖新的远程图片或首页网络请求。

## 当前实现证据与问题

- `web/src/pages/home/index.tsx:24-37`：主页加载时请求远程提示词资源，并维护图片预览状态；离线或源数据为空时，展示区会空白。
- `web/src/pages/home/index.tsx:45-66`：首屏主要是超大标题和两个 CTA，信息密度低；两个入口最终都落到画布相关页面，层级重复。
- `web/src/pages/home/index.tsx:68-109`：第二屏只展示提示词，不能代表画布、生图、视频、素材等完整能力。
- `web/src/styles/globals.css:142-169`：持续运行的标题渐变动效只服务当前主页，替换后可删除，避免无意义常驻动画。
- `web/src/router.tsx:21-27` 与 `web/src/constant/navigation-tools.ts:3-34`：五类核心入口已经存在，无需改路由结构。
- `web/src/pages/canvas/index.tsx:31-37,64-68`：现有 `/canvas?mode=new` 与 `/canvas?mode=recent` 已支持“新建”和“继续最近画布”。
- `web/src/stores/canvas/use-canvas-store.ts:23-32,62-133`：最近画布可直接从本地 Zustand/IndexedDB 状态读取，无需后端。
- `web/src/stores/use-asset-store.ts:28-36,66-104`：最近素材同样可从本地状态读取，并已具备水合状态。

## 联网调研结论（2026-07-14）

### 参考产品

1. **Adobe Firefly 应用首页** — https://firefly.adobe.com/
   - 首屏直接提供生成输入与模型/媒介选择，下方用可点击任务卡承接具体创作能力。
   - 借鉴点：应用内主页首先完成任务分流，而不是重复营销介绍。
2. **Runway 应用首页** — https://app.runwayml.com/
   - 以 “What do you want to create?” 为入口，用 Starter Kits 和推荐工具按创作意图组织能力。
   - 借鉴点：用任务语言描述入口；工具数量多时仍保持清晰层级。
3. **FLORA** — https://flora.ai/
   - 直接在首屏展示节点、连线和生成结果组成的真实工作流，迅速解释“无限画布”的价值。
   - 借鉴点：展示产品工作方式；不照搬其点阵画布和居中 hero，因为当前主页已经接近这种表达。
4. **Krea** — https://www.krea.ai/
   - 用克制的标题、清晰 CTA 和产品界面实景建立信任，避免抽象功能堆砌。
   - 借鉴点：首屏需要让用户看到产品形态，而不只是品牌名。

### 规范依据

- Ant Design 的设计价值强调 Natural / Certain / Meaningful / Growing：https://ant.design/docs/spec/introduce/
- WCAG 2.2 文本对比度：普通文本至少 4.5:1，大文本至少 3:1：https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html
- WCAG 2.2 指针目标最小 24×24 CSS px：https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html
- `prefers-reduced-motion` 应用于移除非必要运动：https://web.dev/articles/prefers-reduced-motion

## 推荐设计方向

### 方向：Editorial Creative Console（编辑式创作控制台）

- **气质**：克制、专业、带轻微实验感；从当前“黑白点阵宣传页”转向“可立即使用的创作桌面”。
- **色彩**：沿用全局中性色 token，主页局部加入单一暖橙信号色；浅色为暖纸面，深色为石墨底，不改全局主题系统。
- **排版**：非对称 12 栏布局，大标题缩至合理阅读尺度；取消荧光笔和循环渐变标题。
- **形状**：薄边框、16-24px 圆角、低阴影；使用大留白但不制造空屏。
- **动效**：只保留 160-220ms hover/focus 微交互，无常驻漂浮、视差或循环动画；兼容 reduced motion。
- **素材策略**：当前首页素材全部弃用。首屏工作流预览由 CSS、内联 SVG 连线、Lucide 图标和本地用户数据组成；无本地数据时显示抽象占位，不新增远程依赖。

## 页面信息架构

1. **Hero / 创作主入口**
   - 左侧：任务导向标题、短说明、“新建画布”主 CTA、“继续上次创作”次 CTA。
   - 右侧：小型工作流预览，用“想法 → 生成 → 编排/复用”节点解释产品；存在本地素材时可显示最近缩略图，否则使用稳定的本地抽象视觉。
2. **快速开始**
   - 画布、生图、视频、提示词四张任务卡；素材库作为“管理与复用”入口。
   - 卡片使用用户意图文案，例如“组织视觉流程”“快速生成一张图”，而非只写功能名。
3. **继续创作**
   - 水合完成且存在项目时，展示最近更新的 3 个画布，显示名称、节点数、更新时间并可直接打开。
   - 无项目时展示简洁的新手路径，不显示空白骨架或错误提示。
4. **最近素材（条件展示）**
   - 仅在存在本地图片/视频素材时显示最多 4 项；没有数据时整个区块隐藏，不制造空区域。

## 可测试验收标准

1. 访问 `/` 不再调用 `fetchPrompts` 或任何只为首页展示服务的远程接口。
2. 新用户在零项目、零素材、离线状态下仍看到完整 hero、5 个核心入口和明确的新建画布 CTA，无空白展示区、破图或错误 toast。
3. “新建画布”进入 `/canvas?mode=new` 对应流程；“继续上次创作”在有项目时进入最近项目，无项目时降级为新建流程。
4. 画布、生图、视频、提示词、素材五项均能从主页一击到达正确路由。
5. 有项目时最多展示最近更新的 3 个；有图片/视频素材时最多展示 4 个；主页只读，不修改 store 数据。
6. 390px 宽度无横向滚动、文字截断遮挡或不可点击重叠；1440px 首屏能同时看到主 CTA、工作流预览和快速开始入口。
7. 浅色/深色、中文/英文均无硬编码不可读文本；普通文本对比度 ≥4.5:1，大文本 ≥3:1。
8. 所有交互可键盘聚焦，点击目标不小于 24×24 CSS px；装饰性图形不进入可访问性树。
9. 无常驻循环动画；系统启用 reduced motion 时取消非必要位移/缩放。
10. 不新增 npm 依赖；`npm run format:check` 与 `npm run build` 通过。

## 风险与缓解

- **本地 store 尚未水合导致闪烁**：未水合时只显示稳定的通用入口；最近内容在水合后渐进出现，不使用大面积骨架。
- **用户素材比例不一致**：缩略图固定容器并使用 `object-cover`，视频增加类型标识，失败时显示本地抽象占位。
- **主页代码变大**：仅抽取同文件内的小型展示函数；不新增转发组件和多层 props。
- **与现有未提交改动冲突**：执行前再次读取工作树，只编辑上述精确区域，不回滚或覆盖其他修改。
- **风格与全局页面割裂**：保留现有导航、主题 token、Ant Button 和 Lucide 图标；暖橙只作为主页信号色而非重写全局主题。

## 停止条件

- 本计划经用户明确批准前，不修改 `DESIGN.md`、主页源码、文案或全局样式。
- 实施完成后，仅在所有验收项有证据且无已知错误时交付；否则继续修复，不扩大到非主页页面。
